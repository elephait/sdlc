# denistek

Personal engineering notes, prompts and reusable agent skills.

- `md/` notes and research. `md/CLAUDE.md` holds the working principles for coding and research.
- `skills/` agent skills, one directory each. See [skills/README.md](skills/README.md).
- `scripts/validate-skills.py` checks every skill against the local conventions: `python scripts/validate-skills.py`.

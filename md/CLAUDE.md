## Coding
- Before writing code, search the project for code that already does the job and import it. Don't copy blocks between files.
- Keep entry files thin (wiring and input/output). Each feature gets its own module.
- Keep files reasonably small and cohesive.
- Dependencies point one way, no cycles, no work at import time.
- Before saying done: compile, import each module from another folder, test with synthetic input, and say what wasn't run.

## Research
- Fetch full pages, not snippets. Anything without a source goes in a Gaps list.
- Important claims need two independent sources. State conflicts, and separate verified from told.
- A failed tool is a retrieval limit, not a conclusion.
